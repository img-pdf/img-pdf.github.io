Reporting Technical Bugs

To help us resolve errors quickly, please include:

  • The specific tool URL (e.g. /image-tools/image-compressor/).
  • Your web browser and operating system version (e.g., Chrome on Windows 11, Safari on iOS).
  • The file extension and rough dimensions of the asset that caused the issue.
  • Any error message displayed in the status line or browser developer console.

Open Roadmap & Project Ethos
