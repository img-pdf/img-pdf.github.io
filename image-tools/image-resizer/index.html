About the Image Resizer

Different platforms expect different dimensions — a profile photo, a product thumbnail, a banner ad. This tool sets your image to an exact pixel width and height, and can lock the aspect ratio so the proportions stay correct while you type.

How to resize an image

  1. Drag your image into the box above, or choose it from your files.
  2. Type a new width or height — the other field fills in automatically if the ratio is locked.
  3. Uncheck the lock if you need an exact, non-proportional size.
  4. Click Resize Image and download the result.

Frequently asked questions

Will resizing distort my image?

Only if you turn off "Lock aspect ratio" and enter dimensions that don't match the original proportions. Keep the lock on to resize without stretching.

Is my image uploaded anywhere?

No — the resize happens using your browser's canvas engine. The file stays on your device.

Can I make an image bigger, not just smaller?

Yes. Enlarging a small image beyond its original size will look softer, since no new detail is created.

What formats are supported?

Upload JPG, PNG, WebP or GIF. The resized file downloads in the same format, except GIF, which exports as PNG.
