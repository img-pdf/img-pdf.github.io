About the Image Compressor

Large photos slow down websites, fill up phone storage and make emails bounce. This tool re-encodes your JPG, PNG or WebP image at a smaller file size, using the same compression your browser already knows how to do — you just get control over the quality/size trade-off with a slider instead of guessing.

How to compress an image

  1. Drag your image into the box above, or choose it from your files.
  2. Move the quality slider — lower means a smaller file, higher means closer to the original.
  3. Optionally set a max width if you also want to scale the image down.
  4. Click Compress Image and download the result.

Supported formats

Upload JPG, PNG, WebP or GIF. Export as JPEG, PNG or WebP. JPEG and WebP support adjustable lossy compression; PNG stays lossless, so its file size reduction will be smaller.

Frequently asked questions

Is my image uploaded to a server?

No. Compression happens using your browser's built-in canvas engine. The file never leaves your device.

Which image formats are supported?

You can upload JPG, PNG, WebP or GIF, and export as JPEG, PNG or WebP.

Is the image compressor free?

Yes — free, with no signup and no limit on how many images you compress.

Does compression reduce image quality?

JPEG and WebP compression is lossy, so a smaller file trades off some quality — the slider lets you choose that balance. PNG export stays lossless.

Can I compress multiple images at once?

Right now this tool handles one image at a time. Batch compression is planned.
