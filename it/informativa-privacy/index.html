Informativa sulla Privacy

Per ImgPDF la tutela della privacy non è una clausola accessoria, ma il principio costruttivo dell'intero software. I tuoi documenti vengono gestiti nella memoria del tuo browser e mai trasferiti a server esterni.

Ultimo aggiornamento: Novembre 2026

1. Garanzia di Elaborazione Locale nel Browser

Quando utilizzi gli strumenti di ImgPDF, i tuoi file vengono aperti unicamente nella sessione del tuo browser web. Nessun file o dato binario viene trasmesso, salvato o esaminato da server esterni.

2. Statistiche di Utilizzo del Sito

Utilizziamo Google Analytics 4 (GA4) e Google Tag Manager (GTM) esclusivamente per misurare il traffico aggregato e migliorare l'esperienza d'uso. Filtri dedicati impediscono l'invio di nomi di file o informazioni personali alle piattaforme di analisi.

3. Hosting e Fornitori di Rete

Il sito è ospitato in forma statica su GitHub Pages e reti CDN globali. Questi sistemi registrano log di rete standard (come indirizzi IP e orari delle richieste) necessari per garantire sicurezza e velocità di consegna dei file statici.

4. Contatti per la Privacy

Per domande sull'informativa o sulla nostra tecnologia lato client, puoi scrivere a privacy@img-pdf.org.
