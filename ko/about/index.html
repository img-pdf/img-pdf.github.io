ImgPDF 소개

ImgPDF는 확고한 소프트웨어 철학 위에 설립되었습니다. 일상적인 문서 작업을 위해 소중한 개인 문서와 사진을 굳이 외부 서버로 전송할 필요가 없어야 합니다.

우리의 사명과 기술 철학

대다수의 파일 변환 사이트는 기밀 계약서나 개인 사진을 원격 서버로 업로드하도록 요구합니다. 저희는 프라이버시가 프리미엄 기능이 아닌, 모든 사용자에게 기본으로 보장되어야 할 권리라고 믿습니다.

클라이언트 사이드 컴퓨팅 원리

최신 웹 표준(HTML5 Canvas, PDF.js, pdf-lib, Web Cryptography)을 활용하여 모든 처리를 브라우저 안에서만 실행합니다. 사용자 기기의 CPU 파워를 활용하므로 인터넷으로 데이터가 오가지 않습니다.

엔지니어링 약속

  • 서버 저장 제로: 업로드 수신용 파일 서버를 아예 운영하지 않습니다.
  • 무료 원칙: 핵심적인 모든 도구는 언제나 무료로 제공됩니다.
  • 간결함과 속도: Cal.com 스타일의 군더더기 없는 빠른 인터페이스를 추구합니다.
