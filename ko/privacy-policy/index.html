개인정보 처리방침

ImgPDF에서 개인정보 보호는 단순한 법적 약관이 아니라 서비스 설계의 근본적인 뼈대입니다. 문서는 오직 사용자의 브라우저 메모리 안에서만 처리되며 서버로 전송되지 않습니다.

최종 업데이트: 2026년 11월

1. 100% 브라우저 로컬 연산 보장

ImgPDF 도구를 사용할 때 선택된 파일은 오직 사용자의 웹 브라우저 탭 세션 내부에서만 열립니다. 어떠한 파일 데이터나 바이너리 콘텐츠도 외부 서버로 전송, 저장 또는 열람되지 않습니다.

2. 웹 로그 및 통계 분석

서비스 개선과 트래픽 분석을 위해 Google Analytics 4 (GA4) 및 Google Tag Manager (GTM)를 익명 집계 형태로 사용합니다. 파일 이름, 문서 내용, 민감한 개인 식별자는 브라우저 필터에 의해 분석 툴로 전송되지 않습니다.

3. 호스팅 및 제3자 인프라

본 웹사이트는 GitHub Pages 및 글로벌 CDN 네트워크를 통해 정적 파일 형태로 호스팅됩니다. 이러한 인프라는 보안 및 안정적인 콘텐츠 전송을 위해 표준 웹 로그(IP 주소, 브라우저 종류 등)를 기술적으로 기록할 수 있습니다.

4. 문의처

본 개인정보 처리방침이나 브라우저 클라이언트 연산 방식에 관해 문의 사항이 있으시면 privacy@img-pdf.org로 연락해 주시기 바랍니다.
