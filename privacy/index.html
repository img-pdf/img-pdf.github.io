Privacy Policy

Last Revised: November 2026.

At ImgPDF (accessible from https://img-pdf.github.io/), the privacy and confidentiality of our visitors are fundamental tenets of our engineering philosophy. This Privacy Policy details the types of information we process, how our client-side architecture safeguards your files, and how limited analytics and content distribution networks operate.

1. Your Files & Documents: Zero-Server Processing

Every tool marked "Private by Design" across ImgPDF executes 100% locally on your computer, tablet, or smartphone:

  • Image Compression, Resizing & Cropping: Executes via the standard HTML5 Canvas 2D engine inside your browser's private memory heap.
  • PDF Merging, Splitting & Conversion: Executes via open-source JavaScript web libraries (pdf-lib) running locally in your browser.
  • Password, Hash & UUID Generation: Executes via the standardized W3C Web Cryptography API (crypto.getRandomValues, crypto.subtle.digest).

Verification of Local Execution

You can verify this yourself at any time: open your browser's Developer Tools (F12) to the Network tab, disconnect your Wi-Fi, and perform an image compression or PDF merge. The operation will execute and download normally because zero bytes are sent to any server.

2. Log Data and Web Traffic Analytics

Like virtually all standard static websites, our static web hosting provider (GitHub Pages) may automatically log basic HTTP technical information when your browser requests web page files (such as index.html, CSS stylesheets, or JavaScript bundles). This typical server log data may include your IP address, browser user-agent string, operating system, referring URL, and the timestamp of page requests.

We do not combine this server log information with personal identifiers or build cross-device tracking profiles.

3. Cookies and Local Storage

ImgPDF does not utilize tracking cookies, marketing cookies, or persistent profiling beacons.

We utilize the browser's native localStorage API solely to remember your preferred visual theme (Light Mode vs. Dark Mode). This preference stays on your personal device and is never transmitted over the internet.

4. Third-Party CDNs (Content Delivery Networks)

To ensure fast global page delivery, certain static utility scripts (such as Google Fonts or pdf-lib on jsDelivr) may be loaded from public content delivery networks. When your browser requests these static scripts, standard HTTP headers are transmitted to the CDN, identical to loading any standard website asset. The CDN receives only the script request and has zero access to the files or images you process within the tool.

5. Advertising Policies & Compliance

In the event that contextual advertising partners (such as Google AdSense) are integrated in the future to help cover hosting and domain maintenance costs, such partners will be strictly bound by standard privacy requirements. We will never sell, lease, or distribute user-supplied file data.
