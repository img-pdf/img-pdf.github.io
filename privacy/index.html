Privacy Policy

Last Revised: November 2026.

At ImgPDF (accessible from https://img-pdf.github.io/), the privacy and confidentiality of our visitors are fundamental tenets of our engineering philosophy. This Privacy Policy details the types of information we process, how our client-side architecture safeguards your files, and how limited analytics and content distribution networks operate.

1. Your Files & Documents: Local Client-Side Execution

Every file utility across ImgPDF executes locally on your personal computer, tablet, or smartphone:

  • Image Processing (Compressor, Resizer, Converter, Cropper): Operates via standard HTML5 Canvas 2D APIs inside your browser's private memory heap.
  • PDF Operations (Merge, Split, JPG to PDF): Operates via open-source JavaScript web engines (pdf-lib) running client-side.
  • PDF to Image Conversion: Operates via Mozilla's PDF.js rendering engine running locally in your browser to generate JPG/PNG page rasters.
  • Cryptographic Utilities (Password, Hash, UUID): Operates via the standardized W3C Web Cryptography API (crypto.getRandomValues, crypto.subtle.digest).

Verification of In-Browser Execution

You can verify client-side execution at any time: open your browser's Developer Tools (F12) to the Network tab, load any tool page, disconnect your internet or enable Offline mode, and run a conversion, compression, or merge. The tool will process and download normally because no files, file contents, or document data are ever uploaded to ImgPDF servers.

2. Web Traffic Analytics & Google Tag Manager

To understand general website performance, identify broken links, and prioritize tool improvements, ImgPDF uses Google Tag Manager (Container ID: GTM-MH56QT6Z) and Google Analytics 4 (Measurement ID: G-PHWHL604R1).

What is collected by Analytics:

  • Aggregated page visits, landing pages, and navigation paths (e.g. visits to /blog/ or /image-tools/).
  • General device characteristics (e.g. mobile vs. desktop, browser type, operating system, screen resolution).
  • Approximate geographic region (derived from IP address by Google at the country/city level; IP addresses are anonymized and not stored by ImgPDF).
  • Traffic sources (e.g. search engine referrals or direct visits).
  • High-level aggregated tool usage counts (e.g., total count of files selected, tool category, download completion type).

Strict Privacy Guarantee: Analytics telemetry strictly excludes all file contents, file names, file paths, passwords, personal identifiers, and document data. Our tracking helper sanitizes all event payloads to prevent any sensitive data transmission.

3. Cookies and Local Storage

Cookies: When Google Tag Manager and Google Analytics run, Google Analytics may set first-party cookies (such as _ga and _ga_*) to differentiate anonymous user sessions and distinguish unique visitors over time. You can block or delete cookies through your browser's security settings or install the official Google Analytics Opt-out Browser Add-on without affecting tool functionality.

Local Storage: ImgPDF utilizes the browser's native localStorage API exclusively to remember your preferred visual theme (imgpdf_theme: Light Mode vs. Dark Mode). This string is stored strictly on your device and is never transmitted over the network.

4. Third-Party CDNs and External Services

The following external services are involved in serving website assets:

  • Google Fonts: Web fonts (Space Grotesk, Inter, JetBrains Mono) are loaded from fonts.googleapis.com and fonts.gstatic.com to provide readable typography.
  • Google Tag Manager & Analytics: Tracking libraries are delivered asynchronously via googletagmanager.com.
  • GitHub Pages: Our static hosting infrastructure, provided by GitHub, Inc., logs standard HTTP server requests (IP addresses, request headers, timestamps) to monitor service integrity and maintain availability.
  • Local Vendor Libraries: Core PDF conversion assets (such as PDF.js and JSZip) are hosted directly within the ImgPDF repository to minimize external third-party network dependencies.

5. Advertising Policies & Compliance

In the event that contextual advertising partners (such as Google AdSense) are displayed on non-tool informational pages to help cover domain and maintenance expenses, advertising partners will be strictly bound by standard privacy requirements. We will never sell, lease, or distribute user file data or personal details.
