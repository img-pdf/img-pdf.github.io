Privacy Policy

Last updated: 2026.

Your files

Tools marked "private by design" process your file entirely in your browser, using built-in APIs like Canvas, Web Crypto, and JavaScript PDF libraries loaded from a CDN. Your file is never uploaded to a server or seen by ImgPDF. This applies to every tool currently live on the site — the compressor, resizer, JPG-to-PDF converter, password generator and QR code generator all work this way.

If a future tool ever requires server-side processing, that page will say so explicitly before you use it.

Analytics

Basic, privacy-respecting analytics may be used to see aggregate traffic (which pages get visited, roughly how many people), without tracking you individually across sites or building an ad profile.

Third-party libraries

Some tools load a small JavaScript library from a public CDN (for example, a PDF-generation library) to do the actual processing in your browser. Loading that script means your browser makes a request to the CDN, the same as loading a font or an image would — the CDN does not receive your files.

Cookies

ImgPDF does not use cookies for tracking or advertising.

Changes to this policy

If this policy changes materially, the "last updated" date above will change too.
