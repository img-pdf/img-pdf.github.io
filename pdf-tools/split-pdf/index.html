How to Split a PDF Online

  1. Select PDF Document: Drag and drop your PDF file into the dropzone above, or click to choose from your computer or phone.
  2. Choose Splitting Mode: Select Extract Custom Page Range (to extract specific pages like "1-3, 5, 8") or Split Every Page Individually (to save each page as its own standalone PDF).
  3. Enter Page Numbers: If using custom range mode, type page numbers and ranges separated by commas.
  4. Split Document: Click Split PDF to process pages locally inside your browser via pdf-lib.
  5. Download: Click the download links for your newly created PDF files.

When Should You Split a PDF?

Large multi-page documents frequently contain sections you need to isolate — extracting a specific signed contract page, pulling financial disclosures from an annual report, or dividing chapters of an eBook for focused review. ImgPDF enables you to extract exactly the pages you need in seconds without installing bulky desktop software.

Limitations & Troubleshooting

Can I split a password-protected or encrypted PDF?

No. Encrypted PDFs prevent reading page cross-references without authentication. You will need to remove the password before uploading the file to the browser tool.

How does page numbering work?

Page numbering uses physical page order starting at 1 for the very first page of the document. Even if your PDF's internal preface uses Roman numerals (i, ii, iii), page 1 refers to the first physical sheet.

What is the maximum number of pages I can split?

Because splitting compiles entirely in device RAM, documents with hundreds of pages work smoothly on modern laptops and PCs. When bursting a 200+ page document into individual files on mobile phones, downloading dozens of separate files may be cumbersome; we recommend extracting smaller page ranges when on mobile devices.

Frequently Asked Questions

How do I extract a range of pages like 2 to 5?

Enter "2-5" into the page range field. You can also combine individual pages and ranges using commas, such as "1, 3, 5-8".

Are my confidential contracts or financial PDFs secure?

Yes. ImgPDF executes memory-safe PDF extraction locally via pdf-lib in your browser. The file is never transferred to any remote server or stored in any database.
