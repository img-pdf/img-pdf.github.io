About ImgPDF

ImgPDF is a free collection of tools for images, PDFs and everyday utilities that run directly in your browser. There's no account to create and, for tools marked private-by-design, nothing gets uploaded to a server — the processing happens on your own device using standard browser APIs like Canvas and Web Crypto.

Why it's free

The tools use client-side JavaScript rather than a backend, so there's no server cost per file processed. That keeps the site free to run and free to use, with no per-use limits.

What's built so far

ImgPDF is being built out one tool at a time rather than launched all at once. Anything linked from the navigation and homepage is live and working; anything marked "soon" is planned but not built yet.

Who's behind it

ImgPDF is an independent, hobby-built project. It isn't affiliated with iLovePDF, iLoveIMG, or any other file-tool company.

Questions or feedback

This is a young project, so if something's broken or a tool you need isn't listed yet, that's expected — more are on the way.
