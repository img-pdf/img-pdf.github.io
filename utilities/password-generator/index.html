About this Password Generator

A good password is long, random, and unrelated to anything guessable about you. This tool builds one from a cryptographically secure random source, with sliders to control length and which character types are included, so you can match whatever a site's password rules require.

How to use it

  1. Adjust the length slider — 16+ characters is a solid default.
  2. Toggle which character types to include.
  3. Click Generate New Password for a fresh one, or copy the current one.

Frequently asked questions

Is this password generator secure?

Yes — it uses crypto.getRandomValues, the same cryptographically secure randomness source used for encryption keys, rather than Math.random, which isn't safe for this purpose.

Are generated passwords sent anywhere?

No. The password is generated and shown entirely in your browser — it's never transmitted or logged.

How long should my password be?

12 characters is a reasonable minimum today; 16 or more with mixed character types is safer, especially for accounts that are hard to recover.
