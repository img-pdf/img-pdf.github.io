About the UUID Generator

A UUID (universally unique identifier) is a 128-bit value used to identify things — database rows, sessions, request IDs — without needing a central counter. Version 4 UUIDs are generated from random bits, and the odds of a collision are astronomically small.

Frequently asked questions

What version of UUID does this generate?

Version 4 — randomly generated, the most common type for database IDs and session tokens.

Are the UUIDs sent to a server?

No — they're generated locally using your browser's crypto API and never transmitted.

Can I generate more than one at a time?

Yes, set the count up to 50 and generate them all at once, with a copy-all option.
