Hash Generator

Generate SHA-1, SHA-256, SHA-384 and SHA-512 hashes from text, computed by your browser's built-in crypto API.

🔒
Private by designHashing uses your browser's built-in Web Crypto API. Your text is never sent to a server.

About the Hash Generator

A hash turns any text into a fixed-length string of characters — the same input always produces the same hash, and even a tiny change in the input produces a completely different one. That makes hashes useful for checking that a piece of text or a downloaded file matches what it's supposed to be.

Frequently asked questions

Why isn't MD5 available?

Browsers don't include MD5 in their built-in crypto API, and MD5 is considered broken for security purposes anyway. This tool only offers SHA algorithms that are natively supported and still considered secure.

Is my text sent to a server to be hashed?

No — hashing uses your browser's built-in Web Crypto API and happens entirely on your device.

What's a hash used for?

Checking that a file or message hasn't been altered, or generating a fixed-length fingerprint of text without storing the original.
