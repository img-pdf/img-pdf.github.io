About Base64

Base64 turns arbitrary bytes into a string of printable characters, which is why it shows up in data URLs, email attachments, and API tokens — formats that expect text, not raw binary. It's not encryption; anyone can decode it back instantly.

Frequently asked questions

Does this handle emoji and non-English text?

Yes — text is converted to UTF-8 bytes before encoding, so accented characters, emoji and non-Latin scripts round-trip correctly.

What happens if I try to decode invalid Base64?

The tool shows an error instead of guessing — Base64 has a strict format, and invalid input can't be reliably decoded.

Is my text sent to a server?

No — encoding and decoding happen entirely in your browser.
