About URL encoding

URLs can only safely contain a limited set of characters. Anything outside that set — spaces, ampersands, non-Latin text — gets replaced with a percent sign followed by its hex code, so it survives being sent as part of a web address.

Frequently asked questions

What's the difference between the component mode and full URL mode?

Component mode escapes every special character, including & and =, which is right for a single query parameter's value. Full URL mode leaves structural characters like :, / and ? alone, since those belong in a complete URL.

Is my text sent to a server?

No — encoding and decoding use your browser's built-in JavaScript functions and never leave your device.
